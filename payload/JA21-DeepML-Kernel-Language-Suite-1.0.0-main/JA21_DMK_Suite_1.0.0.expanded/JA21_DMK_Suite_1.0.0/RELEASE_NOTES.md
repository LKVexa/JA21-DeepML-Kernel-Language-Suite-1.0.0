# Release Notes — 1.0.0

## First standalone DeepML Kernel Language suite

This release transforms the supplied coupling-mechanics corpus wrapper into a navigable JA21 sub-suite.

### Added

- A normalized 10,000-record technical corpus with document metadata separated from record data
- A deterministic, stratified 1,000-script `.dmk` example pack
- Script, feature, diagnostic, and technical-corpus catalogs
- A twenty-chapter technical textbook
- A twelve-week curriculum, student workbook, instructor guide, and starter project
- Provisional EBNF and versioned language, compiler, runtime, semantic-operator, R12/MCRT, and conformance contracts
- Offline corpus inspector and structural suite validator
- Preserved reconstructed source assets and original uploaded wrapper
- Governance charter, release catalog, manifest, and checksums

### Corpus facts

- 10,000 records
- 31 features
- 10 proficiency levels, 1,000 records each
- Validation classes: positive 4,000, negative 1,500, boundary 1,000, integration 1,000, security 750, performance 500, determinism 500, interoperability 250, recovery 250, certification 250
- Expected outcomes: pass 7,500, expected_fail 2,500

### Known limitation

No native DeepML Kernel compiler or device runtime was included. Expected outcomes are modeled and have not been executed by this release.
