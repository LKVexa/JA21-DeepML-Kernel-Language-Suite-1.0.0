# Student Workbook

Use this workbook with the textbook and script catalog. Every answer should cite record IDs and separate source facts, expected outcomes, and personal inferences.

## Major exercises

1. Compare ten examples of one feature across all proficiency levels.
2. Build a diagnostic family tree from `DIAGNOSTIC_CATALOG.csv`.
3. Write a parser test for the provisional EBNF.
4. Define a symbolic-shape constraint solver interface.
5. Prove domain coverage for a tiled loop with a tail.
6. Model a data race and repair it with the narrowest synchronization.
7. Specify deterministic and fast reduction profiles.
8. Create R12/MCRT pairs for accepted and rejected kernels.
9. Design an offline deployment threat model.
10. Produce a conformance report schema for a future compiler.
